# ADR 0003: Icon-led visual identity

Status: accepted — 2026-08-14

Use the supplied fox as the identity anchor without deriving a product name. Preserve the original raster app icon and use a separately generated transparent extraction for dark navigation/auth surfaces.

The mark informs black/ivory foundations and a restrained diagonal motif. Soft off-white surfaces, muted mint/coral/blue/sand accents and generous native-like geometry satisfy the product direction without copying a legacy UI or falling into generic SaaS styling.
